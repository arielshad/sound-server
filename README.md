# sound-server

Search many sample sites at once and download what you pick: kicks, snares, hats, 808s, loops,
vocals, FX, foley and instrument one-shots, for music production and AI music generation.
Sibling of [3d-asset-server](https://github.com/arielshad/3d-asset-server), with the same HTTP API,
MCP server, CLI and web UI design.

Status: planning. See [docs/PLAN.md](docs/PLAN.md) and the research in [docs/research/](docs/research/).
